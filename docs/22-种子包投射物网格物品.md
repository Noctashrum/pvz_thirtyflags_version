## 1. 模块职责

| 模块 | 头文件 / 实现 | 职责 |
|------|--------------|------|
| SeedPacket | SeedPacket.h / SeedPacket.cpp | 种子包（冷却计时、卡牌显示、点击拾取、老虎机滚动）与种子栏容器 SeedBank（传送带/种子栏布局） |
| Projectile | Projectile.h / Projectile.cpp | 投射物：豌豆/冰豆/火豆/孢子/卷心菜/西瓜/冰瓜/玉米粒/玉米炮/黄油/星星/尖刺/篮球/僵尸豌豆的运动、碰撞、溅射与绘制 |
| GridItem | GridItem.h / GridItem.cpp | 网格物品：墓碑/弹坑/梯子/传送门/大脑/惊吓罐/松鼠/禅境工具/臭鼬/耙子/I僵尸大脑 |
| LawnMower | LawnMower.h / LawnMower.cpp | 割草机（草坪/水池/屋顶/超级），触发后碾压本行僵尸 |
| Coin | Coin.h / Coin.cpp | 金币/银币/钻石/阳光/各类奖励道具的掉落、落地、消失与收集动画 |

五个模块共同依赖游戏框架基础类型：`GameObject`（基类，提供 mX/mY/mWidth/mHeight/mRow/mRenderOrder/mBoard/mApp 等）、`Board`（棋盘网格/像素换算/僵尸与植物遍历）、`LawnApp`（全局应用单例）、`Reanimation`（动画）、`TodParticle`（粒子）与 `TodAnimateCurve`（动画曲线）。

## 2. SeedPacket 分析

### 2.1 继承关系与职责

- `class SeedPacket : public GameObject`（SeedPacket.h:96）
- `class SeedBank : public GameObject`（SeedPacket.h:130）

## 8. 关键流程说明

### 8.1 种子包冷却与选择（MouseDown / PickPlant）

1. **拾取判定 `SeedPacket::MouseDown`（SeedPacket.cpp:706）**：前置检查暂停/场景/空包；老虎机、宝石迷阵、水族馆关卡走各自 Challenge 分支。普通模式依次校验 `mActive`（未冷却则蜂鸣+教程提示）、`mBoard->CanTakeSunMoney(aCost)`（钱不够则蜂鸣+OutOfMoney 计数）、`mBoard->PlantingRequirementsMet`（升级前提，如加特林需先种双发，缺则显示对应 ADVICE）。
2. **进入拾取态**：成功后把 `mBoard->mCursorObject` 设为 `CURSOR_TYPE_PLANT_FROM_BANK`，写入 `mType/mImitaterType/mSeedBankIndex`，播放 SOUND_SEEDLIFT，最后 `Deactivate()`。
3. **真正种植在 Board::MouseDown**（不在本文件）——当光标落在合法网格时创建 Plant，随后回调 `SeedPacket::WasPlanted`（SeedPacket.cpp:859）：
   - 传送带：`mBoard->mSeedBank->RemoveSeed(mIndex)` 移除该卡；
   - 老虎机：`Deactivate()`；
   - 最后一战（Last Stand）非进攻阶段：`mTimesUsed++` 后仍保持 mActive（可重复用）；
   - 其它：`mTimesUsed++`、`mRefreshing=true`、`mRefreshTime = Plant::GetRefreshTime(...)`。
4. **冷却推进 `SeedPacket::Update`（SeedPacket.cpp:142）**：`!mActive && mRefreshing` 时每帧 `mRefreshCounter++`，超过 `mRefreshTime` 则 `Activate()` 并 `FlashIfReady()`（冷却完成的闪光粒子 + 教程状态推进）。
5. **拾取资格统一由 `CanPickUp`（665）**与 `Draw` 中的灰化（655，钱不够/种植条件不满足时 grayness=128）共同呈现给玩家。

> 补充：`SetPacketType`（1104）在首次装配卡牌时按「升级植物 / 刷新时间 5000 / 3000」预置初始冷却（3500/8000/2000 帧），保证开场有一段等待。

### 8.2 投射物碰撞检测（CheckForCollision）

调用链：`Projectile::Update`（920）→ `UpdateMotion`（713）→ `UpdateNormalMotion`（613，直线类）或 `UpdateLobMotion`（487，抛射类）→ `CheckForCollision`（237）→ `CheckForHighGround`（326）。

`CheckForCollision` 的分支顺序：
1. 孢子寿命 ≥75 帧 / 出界（`mPosX > WIDE_BOARD_WIDTH` 或 `mPosX + mWidth < 0`）→ Die；
2. `MOTION_HOMING`：取 `mTargetZombieID` 目标，矩形重叠且 Y 在目标区间内 → DoImpact；
3. 星形出屏（Y>600 或 <40）→ Die；
4. 豌豆/星形高度差过大（`mShadowY - mPosY > 90`）→ 提前 return（还在高处飞行）；
5. `MOTION_FLOAT_OVER` 无碰撞直接 return；
6. `PROJECTILE_ZOMBIE_PEA`：`FindCollisionTargetPlant` 命中植物则扣血 + 溅落粒子 + Die；
7. 常规：`FindCollisionTarget`（197，取重叠且 X 最小的本行僵尸）命中后，若僵尸在高台且 `CantHitHighGround` 则跳过，否则 `DoImpact(aZombie)`。

碰撞盒由 `GetProjectileRect`（1159）按类型定制；重叠判定统一用 `GetRectOverlap`（>0 即命中，植物目标用 >8）。命中结算 `DoImpact`（801）先 `PlayImpactSound`，再按 `IsSplashDamage` 决定走 `DoSplashDamage`（溅射分摊）还是单目标 `TakeDamage`，随后按类型播放溅落/爆炸粒子，最后 `Die`。

### 8.3 金币动画状态机（CoinMotion）

`CoinInitialize`（28）根据 `CoinMotion` 设置初速/落点：
- FROM_SKY / FROM_SKY_SLOW：竖直下落（vY=0.67/0.33），落点随机 300~550；
- FROM_PLANT：植物吐出（向上+随机水平），scale 从 0.4 渐长；
- COIN：弹跳抛出（向上+随机水平），落点夹在 80~521；
- LAWNMOWER_COIN：立即 Collect；
- FROM_PRESENT：静止，80 帧后自动 Collect；
- FROM_BOSS：从右侧（750）抛出。

每帧 `Coin::Update`（718）三选一：
1. `mFadeCount != 0` → `UpdateFade`（淡出到 0 死亡）；
2. `!mIsBeingCollected` → `UpdateFall`（469）：未落地时重力累加 + 水平移动 + 撞墙反弹；落地后生成弹跳箭头、播落地音、`mDisappearCounter` 累加到 `GetDisappearTime` 触发 StartFade；
3. `mIsBeingCollected` → `UpdateCollected`（594）：飞向目标（阳光左上 / 钱币钱袋 / 奖励中央），到达后 `ScoreCoin` 结算。

`Collect`（1038）是状态机的进入点：由 `MouseDown`（点击）或 `TryAutoCollectAfterLevelAward`（关卡奖励自动收集）触发，按 CoinType 分发结算逻辑（钱/阳光/解锁/禅境/扇形喷钱/可用种子包挂光标）。

### 8.4 割草机触发逻辑

1. **待机**：`LawnMowerInitialize`（12）后 `mMowerState = MOWER_READY`，停在 `mPosX = -160`（左侧场外）。
2. **触发检测 `LawnMower::Update`（163）**：取 `GetLawnMowerAttackRect`（50×80），遍历僵尸；当僵尸满足「同行、非老板、非 PHASE_ZOMBIE_MOWERED、非缠绕海藻目标、受伤害标志匹配」，且与攻击矩形重叠（气球僵尸要求重叠 >20），且「割草机非 READY 或（非蹦极僵尸且有头）」时调用 `MowZombie`。
3. **碾压 `MowZombie`（127）**：READY 态先 `StartMower`（369，置 TRIGGERED、播放动画/音效、记录 `mTriggeredLawnMowers` 与波次）；泳池型走吸入（DieWithLoot），其余走 `MowDown`。
4. **前进**：TRIGGERED 后每帧 `mPosX += aSpeed`（3.33，泳池 2.5，刚吞僵尸时经 BOUNCE_SLOW_MIDDLE 曲线短暂减速），`mPosY` 按行高实时对齐；泳池型调 `UpdatePool` 处理升降；普通割草机落入泳池行（>50）或越界（`> WIDE_BOARD_WIDTH`）则 Die。
5. **收尾**：`Die`（355）移除动画，若还有奖励割草机（`mBonusLawnMowersRemaining`）则补发一枚并以 ROLLING_IN 状态入场。
