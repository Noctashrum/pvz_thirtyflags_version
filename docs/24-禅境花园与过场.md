## 2. ZenGarden 分析（成员表 + 函数索引表）

### 2.1 继承关系与职责

`ZenGarden` 是**无基类的纯逻辑类**（不继承 Widget），由 `Board` 持有（`Board::mZenGarden`），只在 `GAMEMODE_CHALLENGE_ZEN_GARDEN`（禅境花园模式）下驱动。它负责把存档里的 `PottedPlant`（盆栽数据）落地成战场上的 `Plant`，并驱动整套养成循环。

### 2.4 植物状态（PlantNeed / 成长）

**成长阶段 `PottedPlantAge`**（PlayerInfo.h）：`PLANTAGE_SPROUT → SMALL → MEDIUM → FULL`。每次施肥 `PlantFertilized` 年龄 +1，`mTimesFed=0`；浇水 `PlantWatered` 使 `mTimesFed++`。

**需求 `PottedPlantNeed`**（PlayerInfo.h）：`NONE / WATER / FERTILIZER / BUGSPRAY / PHONOGRAPH`。

核心状态机 `GetPlantsNeed`（:814）判定优先级：
1. 夜间植物白天在温室 → NONE（休眠）
2. 独轮车中的植物 → NONE
3. 1 小时内施过肥 或 今天已满足需求 → NONE
4. 水生植物：已长满→跨日 NONE 否则返回 mPlantNeed；未长满→仅真正水族馆返回 FERTILIZER
5. 15 秒内刚浇过水 → NONE
6. `mTimesFed < mFeedingsPerGrow` → WATER（还需继续浇水）
7. 3 秒内刚浇水 → NONE
8. 未长满 → FERTILIZER
9. 跨日 → NONE
10. 已有进阶需求(BUGSPRAY/PHONOGRAPH) → 返回它
11. 兜底 → WATER

关键：`PlantWatered` 浇水后若植物已长满且无需求，会随机指定 BUGSPRAY 或 PHONOGRAPH 进阶需求；`RefreshPlantNeeds` 只对 FULL 且跨自然日的植物做刷新（水生重设浇水时间+随机进阶需求，非水生清需求次日照常）。时间判定普遍用 `__time64_t` 时间戳 + `tm_year/tm_yday` 跨日比较，并带防时钟篡改回退检测。

### 2.5 温室/蘑菇园/水族馆/独轮车区域管理

`GardenType`（ZenGarden.h）：`GARDEN_MAIN / GARDEN_MUSHROOM / GARDEN_WHEELBARROW / GARDEN_AQUARIUM`。

- 种植位静态表（ZenGarden.cpp 头）：`gGreenhouseGridPlacement[]`（32 位 8×4 规则网格）、`gMushroomGridPlacement[]`（8 位单行不规则，模拟洞穴石台）、`gAquariumGridPlacement[]`（8 位单行错落，模拟鱼缸台面）。每项 `{mPixelX,mPixelY,mGridX,mGridY}`。
- `GetSpecialGridPlacements` 按 `mBoard->mBackground`（GREENHOUSE/MUSHROOM_GARDEN/ZOMBIQUARIUM）选表；`PixelToGrid*`/`GridToPixel*` 走查表互转（命中 80×85 格子框）。
- 花盆规则：蘑菇园非水生、水族馆不放花盆；其余放 `SEED_FLOWERPOT`（水生 `anim_waterplants`，陆生 `anim_zengarden`）。
- 水族馆：`MouseDownWithFullWheelBarrow` 拒绝非水生植物；水生植物仅在真正水族馆内才产生肥料需求；`DrawBackdrop` 给移动中的空位画阴影。
- 独轮车：`GARDEN_WHEELBARROW` 是虚拟状态（被携带），不落地、无需求；`GotoNextGarden` 按购买顺序轮换三园与智慧树。

### 2.6 道具（浇水壶/化肥/唱片/蜗牛）与巧克力

- 道具 GridItem 状态在 `GridItemState`（GridItem.h）中：`GRIDITEM_STATE_ZEN_TOOL_WATERING_CAN / FERTILIZER / BUG_SPRAY / PHONOGRAPH / GOLD_WATERING_CAN`。
- `MouseDownWithFeedingTool` 生成道具动画（金水壶 `anim_water_area` 范围洒水），`ZenToolUpdate` 播完调 `DoFeedingTool` 生效（需求↔工具精确匹配）。化肥/杀虫剂立即扣 `mPurchases`，唱片不扣。
- 蜗牛 Stinky（`GRIDITEM_STINKY`）：`StinkyPickGoal` 优先捡地上金币、否则随机游走到有植物的格子；`StinkyUpdate` 状态机（入睡/沉睡/苏醒/爬行/转身）20px 内自动捡币。`ShouldStinkyBeAwake` 由巧克力亢奋(<3600s)或最近唤醒(<180s)决定。
- 巧克力：喂植物 `FeedChocolateToPlant`（`mLaunchCounter=60` 立即产币 + `PlantHighOnChocolate`<300s 加速）；喂蜗牛 `WakeStinky`+残影（`IsStinkyHighOnChocolate`<3600s）。`CanDropChocolate`（已购蜗牛且巧克力<10）才作为战利品掉落。

### 2.7 金币产生

- 持续产出：`PlantUpdateProduction` 满级且"今日已满足需求"的植物周期性投币；`PlantSetLaunchCounter` 让"越久没满足需求产币越慢"（3000~15000 间隔）；`Rand(1000)+分钟加成`<100 金币否则银币。
- 即时奖励：浇水 1 银、施肥 1 金/2 金/钻石、满足需求 1~3 金。
- 出售：`GetPlantSellPrice`（金盏花 150~300、普通 150/300/500、满级夜间/水生 1000、陆生 800）。
- 掉落：`CanDropPottedPlantLoot` 通关冒险且主花园未满时，关卡内掉落盆栽礼物(COIN_PRESENT_PLANT/COIN_AWARD_PRESENT)。

### 5.4 滚动文本内容如何存储

**结论：滚动/字幕文字并非存于 `gCreditsTiming[]`，而是来自三个独立来源：**

1. **片尾制作名单文字**（游戏名/名单/职责/致谢）→ 硬编码本地化字符串资源 `[CREDITS_GAMENAME] / [CREDITS_NAMES1] / [CREDITS_ROLES1] / [CREDITS_NAMES2] / [CREDITS_ROLES2] / [CREDITS_THANKS]`，在 `DrawFinalCredits`（:722）中用固定 Rect 包裹绘制。
2. **MV 中的歌词词条** → `Reanimation` 的 `Words`/`Words2` 文本轨道（REANIM_CREDITS_MAIN2/3 中），`PreLoadCredits` 把它们的 `mFont` 改为 `FONT_BRIANNETOD32BLACK`；`UpdateMovie` 中 `aTrackWords1/2->mTrackColor` 控制显隐。
3. **`gCreditsTiming[]`（268 条）** → 是"逐词时间轴"，每项 `{mFrame(帧), mWordType(口型), mWordX(x 坐标), mBrainType(大脑动作)}`。它**不存文字**，只存"在哪个帧、向日葵该做哪个口型、大脑该飞向哪个 x 坐标"。`GetTiming` 线性查找当前帧落在哪两条之间，`UpdateMovie` 据此把 `mWordType` 映射为向日葵口型图（`WORD_AA→SING2 / WORD_EE→SING3 / WORD_AW→SING4 / WORD_OH→SING5 / WORD_OFF→默认`），并按 `mBrainType` 驱动 `mBrainPosX/Y` 的飞行动画（FLY_ON/FAST_ON/NEXT_WORD/FAST_OFF/FLY_OFF/OFF）。

### 5.5 绘制流程

`Draw`（:748）→ 黑底 → 按阶段裁剪背景(MAIN2/3 的 Background2~4 裁剪平移) → `aCreditsReanim->DrawRenderGroup(g,1)`(背景层) → 泳池/门底/烟囱/灯球/雾(按帧区间开关) → `DrawRenderGroup(g,2)`(僵尸层) → 门掩码/烟囱掩码 → `DrawRenderGroup(g,3)`(词条/前景) → 粒子 → `DrawFogEffect` → 再次 `DrawRenderGroup(g,3)` → 若 `mDrawBrain` 画大脑。

`UpdateMovie`（:1118）逐帧：`UpdateBlink` → `aCreditsReanim->Update()` → `TurnOffTongues` → 阶段切换(靠 `mLoopCount>0` 依次 `PlayReanim(2/3)`→END) → 各阶段按 `ShouldTriggerTimedEvent(帧)` 触发粒子/音效 → `GetTiming` 驱动口型与大脑。

音画同步：`Update`（:1051）用 `mTimerSinceStart` 与 reanim 时长求差，差值 >10000ms 跳帧，>0 则 while 循环 `UpdateMovie` 追帧；`mDontSync`（调试键 n）关闭同步；`PauseCredits` 暂停音乐并弹框；`JumpToFrame` 用音乐偏移表精确跳转并回拨计时器。

## 7. 关键流程说明

1. **禅境花园生命周期**：`Board::NewGame(GAMEMODE_CHALLENGE_ZEN_GARDEN)` → `ZenGarden::ZenGardenInitLevel`（落地盆栽+蜗牛）→ 每帧 `ZenGardenUpdate`（更新需求/盆栽/道具/蜗牛）→ 用户操作经 `MouseDownZenGarden`/`MouseDownWithTool` → 离园 `LeaveGarden`/`GotoNextGarden`/`OpenStore`。
2. **需求→满足→产币闭环**：浇水/施肥推进成长 → 满级后产生进阶需求 → 满足需求进入"开心"状态 → 开心状态周期性产币 → 出售/掉落回笼金币。
3. **过场生命周期**：`StartLevelIntro` 初始化时间轴 → `Update` 逐帧 +10 → `AnimateBoard` 到里程碑触发动作 → 选卡器 `StartSeedChooser`/`EndSeedChooser` → 正式进入 SCENE_PLAYING。失败走 `StartZombiesWon`→`UpdateZombiesWon`→`IsCutSceneOver`。
4. **奖励画面**：关卡胜利 `ShowAwardScreen(AWARD_FORLEVEL)` → `Draw` 按关卡分发 → `StartButtonPressed` 决定去向（下一关/商店/年鉴/禅境/名单）。
5. **名单**：`ShowCreditScreen` → `PreLoadCredits` 预加载 → 首次 `Update` `PlayReanim(1)`+起播音乐 → `UpdateMovie` 逐帧推进三阶段 → `mLoopCount>0` 切段 → END 阶段 `DrawFinalCredits` 画字幕 + 显示重播/主菜单按钮。
