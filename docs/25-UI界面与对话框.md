# UI 界面与对话框模块文档

> 所属: src/Lawn
> 编码说明: 源码为 GBK(代码页936) 编码，本文档统一 UTF-8。
> 行号说明: 函数索引表中"文件:行号"为 `.cpp` 实现文件内的定义起始行（构造函数/析构函数/成员函数）；头文件仅给出类声明与成员布局。

## 1. 模块职责

本模块是《植物大战僵尸》全部 2D UI 界面的实现层，基于自研的 SexyAppFramework 轻量级控件库（Widget / Dialog / Button / Slider / Checkbox / ListWidget / EditWidget 等）。按职责可划分为四类：

1. **顶层屏幕（Screen）**：`TitleScreen`（启动/加载画面）、`GameSelector`（模式选择主菜单）、`SeedChooserScreen`（关卡前选卡）。
2. **商店**：`StoreScreen`（疯戴夫商店，含商品表/价格/购买条件/翻页）。
3. **图鉴**：`AlmanacDialog`（植物/僵尸图鉴，索引 + 分页浏览）。
4. **对话框（Dialog）**：基类 `LawnDialog` 及其派生/相关类 `ReanimationWidget`、`GameOverDialog`、`ContinueDialog`、`NewOptionsDialog`、`NewUserDialog`、`UserDialog`、`CheatDialog`。
5. **辅助缓存**：`ReanimatorCache`（`ReanimationLawn.h/.cpp`，把 Reanimation 动画逐帧预渲染为 `MemoryImage` 位图缓存，供图鉴/商店等 UI 静态展示植物/僵尸/割草机）。

整体设计遵循 "控件组合 + 事件回调（Listener）+ 每帧 Update/Draw 双循环" 的经典模式：每个界面是一个 `Sexy::Widget` 子树，通过 `AddedToManager` / `RemovedFromManager` 挂接/卸载子控件，通过 `ButtonDepress` / `MouseDown` / `KeyDown` 处理交互，通过 `Update` 驱动状态机与动画，通过 `Draw` 自绘。

## 2. TitleScreen —— 启动/加载画面

**文件**：`TitleScreen.h`(69 行) / `TitleScreen.cpp`(536 行)
**继承关系**：`TitleScreen : public Sexy::Widget, public Sexy::ButtonListener`

### 2.1 职责

程序启动后的第一屏。依次播放 PopCap Logo / 合作方 Logo，然后显示 PVZ 标题、加载进度条（含草皮滚卷动画、发芽/僵尸头彩蛋）与 "[LOADING]→[CLICK_TO_START]" 超链接按钮。加载线程完成后点击任意键进入游戏；内测版支持 `mQuickLoadKey` 快速直达各模式的调试后门。

### 2.3 状态机（mTitleState）

```
TITLESTATE_WAITING_FOR_FIRST_DRAW (黑屏等待首帧)
        │  Update() 首帧: 初始化音乐 + StartLoadingThread()
        ▼
TITLESTATE_POPCAP_LOGO  (PopCap Logo 淡入淡出)
        │  counter 归零 → (mDisplayPartnerLogo ? SCREEN : SCREEN)
        ▼
TITLESTATE_PARTNER_LOGO (合作方 Logo，可选)
        │  counter 归零
        ▼
TITLESTATE_SCREEN       (标题画面 + 加载进度条)
```
- 进度条在 `mCurBarWidth` 达到 99% 前受 `mBarVel` 驱动逐步增长；`mLoadingThreadComplete` 后置满 314 并显示 `[CLICK_TO_START]`。
- 进度每越过一个触发点（11%/32%/54%/72%/91%）就种下一颗 "发芽" 动画，末点为 "僵尸头" 动画并播放音效。

## 4. SeedChooserScreen —— 关卡前选卡界面

**文件**：`SeedChooserScreen.h`(141 行) / `SeedChooserScreen.cpp`(1184 行)
**继承关系**：`SeedChooserScreen : public Sexy::Widget`（非 Dialog）；含数据结构 `ChosenSeed`（普通类）。

### 4.1 职责

关卡开始前的选卡：左侧种子栏（chooser，8 列 × 5~6 行）与顶部卡槽（bank）之间通过飞行动画选卡/退卡。核心数据是 `ChosenSeed mChosenSeeds[NUM_SEED_TYPES]` 数组，每格记录一种植物的位置、飞行起止、状态、卡槽索引、刷新、模仿者类型、是否被疯戴夫选中。负责选卡校验（夜间/水池/屋顶/飞行怪/升级卡等警告弹窗）、开始按钮启用逻辑、图鉴/商店跳转、模仿者对话框、查看草坪等。

### 4.4 状态机

**A. 界面状态 mChooseState**
```
CHOOSE_NORMAL ──(点击"查看草坪" / 生存模式重选)──▶ CHOOSE_VIEW_LAWN
CHOOSE_VIEW_LAWN ──(mViewLawnTime>350 或 CancelLawnView)──▶ CHOOSE_NORMAL
```

**B. 单个种子状态 ChosenSeed::mSeedState（核心流程）**
```
SEED_IN_CHOOSER  (在选择栏)
   │ ClickedSeedInChooser: 设置 25 帧飞行动画, mSeedsInFlight++/mSeedsInBank++
   ▼
SEED_FLYING_TO_BANK  (飞向卡槽)
   │ LandFlyingSeed: 落位 → mSeedsInFlight--
   ▼
SEED_IN_BANK  (在卡槽中)
   │ ClickedSeedInBank: 后续种子前移(15帧), 本种子飞回选择栏(25帧)
   ▼
SEED_FLYING_TO_CHOOSER  (飞回选择栏)
   │ LandFlyingSeed → SEED_IN_CHOOSER（模仿者则回到 SEED_PACKET_HIDDEN）
   ▼
SEED_IN_CHOOSER / SEED_PACKET_HIDDEN (模仿者专用：未使用时隐藏)
```

## 14. 关键流程说明

### 14.1 启动流程（TitleScreen → GameSelector）
`TitleScreen` 状态机播放 Logo 并等待加载线程 → 加载完成点击 → `LoadingCompleted()` → `ShowGameSelector()`。`GameSelector` 首帧 `SyncProfile(false)` 读取玩家等级/解锁，`SELECTOR_OPEN` 开场动画后若无玩家则先 `DoCreateUserDialog()`。

### 14.2 进入关卡选卡流程
`GameSelector::ClickedAdventure` → 置 `mStartingGame`，450 帧后 `PreNewGame(GAMEMODE_ADVENTURE)` → 创建 `Board` → `SeedChooserScreen`。构造时：非首次冒险由 `CrazyDavePickSeeds()` 预选 3 张 → 玩家点选 `ClickedSeedInChooser/InBank` 完成选卡 → `OnStartButton()` 逐项校验（阳光/水池/屋顶/飞行怪/升级卡）→ `CloseSeedChooser()` 把卡槽写回 `mSeedBank` → 开战。

### 14.3 商店购买流程
`GameSelector/SeedChooserScreen` 点击商店 → `ShowStoreScreen()` → 构造时 `mPage=0`，`mHatchOpen` 状态决定商品是否可见 → `MouseDown` 命中商品 → `IsFullVersionOnly/PVZ/ComingSoon/SoldOut/Unavailable` 拦截 → `PurchaseItem`：余额不足弹 `DIALOG_NOT_ENOUGH_MONEY`，否则确认 → `AddCoins(-cost)` → 按类别写回 `PlayerInfo::mPurchases`（卡槽升级触发 `mSeedBank->UpdateWidth()`；智慧树置 `mGoToTreeNow`；盆栽 `ZenGarden->AddPottedPlant`）→ `WriteCurrentUserConfig()` → 若选卡界面在场则 `UpdateAfterPurchase()` 刷新。

### 14.4 图鉴浏览流程
`DoAlmanacDialog()` → 索引页 → `MouseDown`/`MouseUp` 点 "查看植物/僵尸" 或直接点网格条目 → `SetPage/ShowPlant/ShowZombie` → `SetupPlant/SetupZombie` 创建离屏展示实例 → `DrawPlants/DrawZombies` 网格 + 卡片描述。僵尸条目按 `ZombieIsShown` 渐进解锁，未遭遇显示剪影/"未遇到"。

### 14.5 对话框通用回调流程
`mApp->DoDialog(id, isModal, header, lines, footer, buttonMode)` 创建 `LawnDialog` 派生实例 → `AddedToManager` 挂接按钮/动画 → 用户点击 → `ButtonDepress(id)`（子类重写分发）→ `mApp->KillDialog(id)` 关闭；调用方常用 `WaitForResult(true)` 同步阻塞获取选择结果。

## 15. 可复用性评估

### 15.1 高复用组合模式（★★★）

1. **动画轨道绑定按钮**（`GameSelector::TrackButton` + `SyncButtons`）：按钮坐标/贴图跟随 Reanimation 轨道变换，解锁态动态切图/置灰/显隐。适用于所有 "动画背景 + 热区" 菜单。
2. **数据驱动商品表**（`StoreScreen::gStoreItemSpots` + `GetStoreItemType` + `GetItemCost` + 三元判定）：新增商品只需改静态表与价格分支，逻辑与展示解耦。
3. **九宫格自适应对话框**（`LawnDialog::CalcSize` + `Resize` + `Draw`）：按字体度量 + 九宫格贴图最小尺寸自动算大小、平铺背景、自动布局按钮，派生类只需传文本/按钮模式。
4. **网格布局 + 命中测试**（`AlmanacDialog::GetSeedPosition/GetZombiePosition` + `SeedHitTest/ZombieHitTest`；`SeedChooserScreen` 同类）：图鉴/背包/选卡等任何网格选择界面通用。
5. **点选飞行动画**（`SeedChooserScreen::ClickedSeedInChooser/InBank` + `LandFlyingSeed`）：以 "起止帧 + 年龄插值" 实现平滑拖拽/点选位移，可复用于卡牌/背包移动。
6. **动画→位图懒加载缓存**（`ReanimatorCache`）：大量重复静态姿态渲染的性能优化范式。

### 15.2 中复用模式（★★）

- 进度条平滑推进 + 触发点彩蛋（`TitleScreen`）；
- 状态机 + 计数器驱动的界面动画（`mSelectorState`/`mTitleState`/`mChooseState`）；
- 内容渐进解锁三级判定（`AlmanacDialog` 僵尸剪影/可见/描述）；
- 表单预检逐项确认（`SeedChooserScreen::OnStartButton`）；
- 商店购买与游戏状态联动（`PurchaseItem` → `UpdateAfterPurchase`）；
- 弹窗阻塞等待结果（`WaitForResult` + `mWaitForDialog`）。

### 15.3 低复用/一次性（★）

- 各类构造函数中繁琐的贴图/坐标硬编码（按钮颜色、偏移、多边形热区）；
- 秘技按键检测（`GameSelector::KeyDown` 大量 `TypingCheck` 分支）；
- 试玩版/完整版、合作方预览版等发行相关分支（`IsTrialStageLocked`、`AddPreviewProfiles`、`gIsPartnerBuild`）。

### 15.4 复用建议

如需移植或二次开发，建议抽取以下可复用单元：
- `DialogButton` 轨道绑定与解锁态同步逻辑（从 `GameSelector` 提炼为通用 `TrackedButton`）；
- 九宫格对话框基类（`LawnDialog` 已较通用，可独立成框架层）；
- 商品/价格/购买状态表驱动框架（从 `StoreScreen` 提炼为 `StoreItemTable`）；
- 网格布局 + 命中测试工具函数（`SeedChooserScreen` 与 `AlmanacDialog` 的坐标计算可统一）。
