## 4. 移植打包建议（按价值排序）

1. **几何/数学包**：`Rect.h + Point.h + SexyVector.h + SexyMatrix.* + Ratio.* + Insets.* + Color.*` —— 无平台依赖；
2. **字符串/格式化包**：从 `Common.h/.cpp` 抽 55 个工具函数 + `LawnApp` 的 Pluralize/GetMoneyString；
3. **数据/算法包**：`MTRand.* + Buffer.* + PerfTimer.* + SmartPtr.h + CritSect.* + TodList.* + TypingCheck.* + KeyCodes.* + DataSync.*`；
4. **解析器栈**：`EncodingParser → XMLParser → PropertiesParser/DescParser`（PakLib 的 `p_fopen` 换成标准 fopen）；
5. **IO 包**：`PakInterface` + `ImageLib`（+ 所需编解码树）；
6. **动画/特效包**：`TodCommon(含 TodAnimateCurve/TodWeightedArray) → Definition/DataArray → Reanimator → TodParticle → Attachment/EffectSystem/Trail`；
7. **mod 开发包（最小集）**：`Definition + DataArray + XMLParser` —— 学会「DefMap 反射 + offsetof 字段表」即可自定义 XML 数据文件让引擎加载；
8. **完整 2D 引擎**：以上全部 + `Widget*` 控件树 + `Graphics/DDImage/DDInterface` 渲染栈 + `ResourceManager` + `Font*`（即 SexyAppFramework 本体；设备层 DDInterface/D3DInterface 为 DirectDraw7/D3D7 历史包袱，建议替换为 SDL/OpenGL/bgfx 后端并保持 Image/Graphics 接口契约）；
9. **游戏算法抽取**：波次调度器（WaveScheduler）、三消板（Match3Board）、分层伤害管线（DamagePipeline）三个最具移植价值的游戏逻辑单元。

## 5. 注意事项（复用前必读）

1. **`SEED_LEFTPEATER` 是原版游戏自带植物**（左向豌豆射手，仅破罐者模式使用，不参与正常选卡），抽取枚举/数据表时**不要**误当作多余条目删除；
2. **编码**：源码 GBK；若跨平台抽取需先转 UTF-8 并处理 `SexyChar/wchar_t` 别名（`_USE_WIDE_STRING` 宏控制）；
3. **依赖注入**：多数游戏代码用全局 `gSexyAppBase/gLawnApp` 与 `TOD_ASSERT`，移植时替换为构造注入；
4. **断言/调试**：`TOD_ASSERT/DBG_ASSERT` 依赖 `TodDebug/Debug.cpp`，抽取工具时需带或替换。
