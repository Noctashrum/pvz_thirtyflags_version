# 植物系统模块文档

> 所属: src/Lawn | 文件: Plant.h / Plant.cpp

## 1. 模块职责

`Plant`（植物）是《植物大战僵尸》游戏对象系统中仅次于 `Zombie` 的核心类。本模块负责：

- **数据表**：通过全局数组 `gPlantDefs`（`PlantDefinition` 结构）定义全部植物的静态属性（阳光费用、冷却、攻击间隔、动画类型、名称键等）。
- **对象模型**：`Plant` 继承 `GameObject`，维护植物的网格坐标、血量、状态机、动画 ID、目标僵尸、磁力物品等运行时状态。
- **行为驱动**：`Update()` → `UpdateAbilities()` 按 `SeedType` 分派到各植物的专属更新函数（`UpdateSquash`、`UpdateChomper`、`UpdateMagnetShroom`、`UpdatePotato`、`UpdateCobCannon` …）。
- **攻击系统**：`UpdateShooter`/`UpdateShooting`/`Fire`/`FindTargetZombie` 构成射手植物的发射管线；范围伤害由 `DoRowAreaDamage` 完成。
- **渲染**：骨骼动画（Reanimation）挂接、眨眼、影子、磁力物品、被压扁/被吃闪烁、升级高亮等表现。
- **静态查询接口**：`GetCost`/`GetNameString`/`GetToolTip`/`GetRefreshTime`/`IsNocturnal`/`IsAquatic`/`IsFlying`/`IsUpgrade` 等供种子包（SeedPacket）、选卡界面（SeedChooserScreen）等调用。

文件规模：Plant.h 326 行；Plant.cpp 5333 行。类成员函数共 **101 个**（详见 §6）。

## 3. gPlantDefs 数据表分析

- **定义位置**：`Plant.cpp` 15–69 行（地址标注 `0x69F2B0`）。
- **条目数**：**53 条**（`SeedType::NUM_SEED_TYPES == 53`，下标 0–52）。
- **索引方式**：按 `SeedType` 数值直接下标索引，`gPlantDefs[theSeedType]`；条目内 `mSeedType` 自校验与下标一致（`GetPlantDefinition` 断言语义）。
- **访问接口**：`PlantDefinition& GetPlantDefinition(SeedType)`（Plant.cpp 5083）。

### 3.1 各字段典型取值区间

| 字段 | 取值区间 / 规律 |
|---|---|
| `mSeedCost` | 0（免费：小喷菇/海蘑菇/模仿者/爆炸坚果/巨型坚果/金盏花苗 Sprout）、25、50、75、100、125、150、175、200、225、250、300、325、500（玉米加农炮）。区间 [0, 500] |
| `mRefreshTime` | 750（快，7.5s）、3000（中，30s）、5000（慢，50s，多为一次性/升级植物）。三档 |
| `mSubClass` | `SUBCLASS_SHOOTER`（豌豆系、投手系、仙人掌、杨桃、香蒲、忧郁菇、双向/三重、加特林、海蘑菇/小喷菇等）与 `SUBCLASS_NORMAL`（其余） |
| `mLaunchRate` | 0（非射手/非产阳光）、150（豌豆系）、200（忧郁菇）、300（投手系：卷心菜/玉米/西瓜/冬瓜）、600（玉米加农炮）、2500（产阳光：向日葵/双子/阳光菇/路灯花/金盏花） |
| `mPacketIndex` | 0–40，多个植物共享同一索引（如 27 被忧郁菇/香蒲/冬瓜/吸金磁/钢地刺共用；33 被胆小菇/花盆/咖啡豆/模仿者/金盏花苗共用） |
| `mPlantName` | 大写英文名键，如 `"PEASHOOTER"`、`"CHERRY_BOMB"`、`"WINTER_MELON"` |

### 3.2 示例条目解析

**豌豆射手**（`SEED_PEASHOOTER`，下标 0）
```cpp
{ SEED_PEASHOOTER, nullptr, REANIM_PEASHOOTER, 0, 100, 750, SUBCLASS_SHOOTER, 150, _S("PEASHOOTER") }
```
- 费用 100，冷却 750ms，射手子类，发射间隔 150 帧，动画 `REANIM_PEASHOOTER`，种子包图集索引 0。

**向日葵**（`SEED_SUNFLOWER`，下标 1）
```cpp
{ SEED_SUNFLOWER, nullptr, REANIM_SUNFLOWER, 1, 50, 750, SUBCLASS_NORMAL, 2500, _S("SUNFLOWER") }
```
- 费用 50，冷却 750ms，普通子类，`mLaunchRate=2500` 表示产阳光间隔（非射手，但 `MakesSun()` 命中后走 `UpdateProductionPlant`）。

**樱桃炸弹**（`SEED_CHERRYBOMB`，下标 2）
```cpp
{ SEED_CHERRYBOMB, nullptr, REANIM_CHERRYBOMB, 3, 150, 5000, SUBCLASS_NORMAL, 0, _S("CHERRY_BOMB") }
```
- 费用 150，冷却 5000ms（慢），普通子类，`mLaunchRate=0`（一次性爆炸植物，不走发射管线）。

## 8. 关键流程说明

### 8.1 种植流程（PlantInitialize）

`PlantInitialize(theGridX, theGridY, theSeedType, theImitaterType)`（99–491）：
1. 记录网格坐标 `mPlantCol/mRow`，换算像素 `mX/mY`。
2. 重置计时器/动画参数，`mPlantHealth=300`、`mWidth=mHeight=80`，从 `GetPlantDefinition` 取 `mLaunchRate/mSubclass`，计算 `mRenderOrder`。
3. 若有 `mReanimationType`：`AddReanimation` 挂身体动画，设循环/速率；保龄球关特殊处理 `_ground` track。
4. 夜间植物（`IsNocturnal`）在非夜晚关卡 → `SetSleeping(true)`。
5. 初始化 `mLaunchCounter`（射手/产阳光植物）。
6. **按 `SeedType` 的 switch 分支**做特殊初始化：豌豆系挂"头"动画；双向/三重挂多头；坚果类血量 4000/8000；土豆雷 1500 帧武装倒计时；樱桃/辣椒/毁灭/冰川的爆炸前奏；墓碑吞噬者落地；阳光菇小态 12000 帧；地刺/南瓜/大嘴花/模仿者/玉米加农炮等初始状态与血量。
7. 大计时挑战（BIG_TIME）坚果/向日葵/金盏花血量翻倍；`mPlantMaxHealth = mPlantHealth`；处理花盆上植物的动画冻结。

> 实际创建入口在 `Board::AddPlant`（非本文件），`PlantInitialize` 是其调用的初始化后端。

### 8.2 攻击（Shoot 相关）流程

```
Update() → UpdateAbilities()
  ├─ UpdateShooting()          // 射击动画进行中（mShootingCounter>0），逐帧递减，在关键帧 Fire
  ├─ (按 SeedType 分派 Update*)  // 特殊植物状态机
  └─ if (mSubclass == SUBCLASS_SHOOTER) UpdateShooter()
        └─ mLaunchCounter-- → 到 0 后重置并：
             ├─ THREEPEATER → LaunchThreepeater()
             ├─ STARFRUIT   → LaunchStarFruit()
             ├─ SPLITPEA    → FindTargetAndFire(…, SECONDARY)
             ├─ CACTUS      → 按高低态选 PRIMARY/SECONDARY
             └─ 其他         → FindTargetAndFire(mRow, PRIMARY)
```

- `FindTargetAndFire`（770）：`FindTargetZombie` 索敌 → `EndBlink` → 播放射击动画（头/身体按 SeedType 分支）→ 设置 `mShootingCounter`（决定后续发射节奏）。
- `UpdateShooting`（3292）：`mShootingCounter` 递减；关键帧调 `Fire`：
  - 加特林在 18/35/51/68 帧各发一发（4 连发）；忧郁菇在 126/98/70/42 帧发（4 次范围毒雾）；香蒲在 19 帧发；三重/双向/投手等在 `mShootingCounter==1` 时发。
- `Fire`（4580）：大喷菇/忧郁菇走范围伤害；杨桃走 `StarFruitFire`；其余按 SeedType 选弹种（豌豆/冰豆/孢子/尖刺/卷心菜/玉米/西瓜/冬瓜/加农炮弹），算出射点（`GetPeaHeadOffset` 等），投手走 `MOTION_LOBBED` 抛物线（`mVelX/mVelZ/mAccZ`），香蒲走 `MOTION_HOMING`，双向向后/反向豌豆走 `MOTION_BACKWARDS`。
- `FindTargetZombie`（4885）：按 `GetDamageRangeFlags` 过滤可伤害类型，按 `GetPlantAttackRect` 判定是否进入射程，权重取"最靠左"（`-aZombieRect.mX` 最大），香蒲优先飞行单位。
- `GetDamageRangeFlags`（597）：确定能命中的僵尸类别位掩码；`DoRowAreaDamage`（710）用于地刺/忧郁菇/大喷菇的范围伤害。

## 9. 可复用性评估

### 9.1 高可复用（★★★）—— 推荐直接复用/参考

- **静态查询族**：`GetCost` / `GetNameString` / `GetToolTip` / `GetRefreshTime` / `IsNocturnal` / `IsAquatic` / `IsFlying` / `IsUpgrade` / `PreloadPlantResources` —— 纯数据驱动、无副作用，是种子包/选卡/图鉴系统的稳定接口。
- **几何与掩码**：`GetPlantRect` / `GetPlantAttackRect` / `GetDamageRangeFlags` / `DoRowAreaDamage` / `FindTargetZombie` —— 索敌与范围伤害的通用范式（"掩码过滤 + 矩形重叠 + 权重择优"）。
- **工具函数**：`PlayBodyReanim` / `AddAttachedParticle` / `DrawSeedType` / `CalcRenderOrder` —— 骨骼动画播放、粒子挂接、静态绘制、渲染排序的通用封装。
- **`GetPlantDefinition`** —— 数据表访问的教科书式封装（带断言自校验）。

### 9.2 中可复用（★★）—— 逻辑清晰、可借鉴迁移

- 生命周期与主循环骨架：`PlantInitialize` / `Update` / `UpdateAbilities`（"switch(SeedType) 分派"范式）/ `Die` / `Squish` / `RemoveEffects`。
- 发射管线：`UpdateShooter` / `UpdateShooting` / `Fire` / `FindTargetAndFire` —— 用 `mShootingCounter` 在动画关键帧触发发射的模式值得借鉴。
- 特殊状态机：`UpdateSquash` / `UpdateChomper` / `UpdatePotato` / `UpdateMagnetShroom` / `UpdateGoldMagnetShroom` / `UpdateCobCannon` 等 —— 均是"`mState` + `mStateCountdown` + `mLoopCount`"驱动的小型状态机，可作同类玩法参考。
- 渲染：`UpdateReanim` / `UpdateReanimColor` / `SetSleeping` / `AttachBlinkAnim` / `AnimateNuts`（按血量切贴图）。

### 9.3 低可复用（★）—— 深度绑定具体植物/动画资源

- 各植物专属的细粒度动画切换（`LaunchThreepeater`、`StarFruitFire`、`AnimatePumpkin`、`DrawShadow` 中逐植物偏移等）—— 与美术资源、track 名强耦合。
- 空构造 `Plant()`、内联空 `UpdateNeedsFood()`。
